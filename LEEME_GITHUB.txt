ALVITEC MARTINEZ - COMPILACION APK CON GITHUB ACTIONS

1. Extrae el ZIP en tu computadora.
2. En GitHub abre tu repositorio ALVITEC-Cotizador.
3. Pulsa Add file > Upload files.
4. Sube el contenido de la carpeta ALVITEC_Cotizador_Android, incluyendo la carpeta .github.
5. Pulsa Commit changes.
6. Abre la pestaña Actions y selecciona Generar APK ALVITEC.
7. Si no comenzó automáticamente, pulsa Run workflow.
8. Cuando termine correctamente, abre la ejecución y descarga el artefacto ALVITEC-Cotizador-APK.
9. Dentro del ZIP descargado estará app-debug.apk.

Nota: este APK es de depuración para instalar y probar. No compartas contraseñas ni tokens.
